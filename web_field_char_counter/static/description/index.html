Field Character / Word Counter — A Live Counter Under Any Field

Two drop-in field widgets that add a small, live counter under a field as you type — turns red once you're past the limit. Handy for SEO meta descriptions, tag lines, or any field with a soft length guideline that Odoo doesn't enforce on its own.

✓ Odoo 17.0✓ Odoo 18.0✓ Odoo 19.0

How it works

  1. Add widget="char_counter" (single-line) or widget="text_counter" (multi-line) to a field in a view.
  2. Optionally set counter_max and counter_type in the field's options (see Usage below).
  3. Start typing — the live count appears under the field and turns red past the limit.

Details

  • char_counter for single-line Char fields, text_counter for multi-line Text fields — both otherwise behave exactly like the standard widget, the counter is purely additive.
  • counter_max (optional): the target length. If the field already has a native size limit, it's used automatically when counter_max isn't set.
  • counter_type (optional): characters (default) or words.
  • The counter never blocks typing or saving — it's a visual guide only.

Usage

<field name="website_meta_description" widget="char_counter"
       options="{'counter_max': 160}"/>

<field name="description" widget="text_counter"
       options="{'counter_max': 500, 'counter_type': 'words'}"/>

Frequently asked questions

Does the counter stop me from saving over the limit?
No — it's a visual guide only. It never blocks typing or saving; the field just turns red past the limit.
Does it work on Html/rich-text fields?
No — char_counter is for Char fields, text_counter for plain Text fields. Html/WYSIWYG fields aren't supported.
What if I don't set counter_max?
If the field has a native size limit (a Char field with a size), it's used automatically; otherwise the widget just shows a running count with no target.
